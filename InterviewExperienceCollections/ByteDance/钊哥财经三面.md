# 钊哥字节财经三面

##

### 一、 个人背景与实习意向

1. 先简单介绍一下个人情况。
2. 你的专业是怎么选的？本科是机器人工程（控制类），研究生为什么去读生物医学工程？为什么没有选计算机相关的专业？
3. 你们专业的同学正常大部分毕业后去哪里（什么行业）就业？
4. 你现在是想找互联网公司吗？毕业之后的规划是什么？
5. 之前去别的公司实习过吗？你们实验室或者同学有去互联网公司实习的吗？
6. 你能实习多久？每周可以实习几天？什么时候可以开始？

### 二、 项目经历（天天神券 / 本地生活）

1. 你的“天天神券”等项目，是你自己做的开源实验项目吗？
2. 大概讲讲“天天神券”这个项目的系统架构是什么样的？系统模块是怎么划分的？
3. 在这个项目里，你觉得你遇到的难点是啥？

### 三、 计算机基础理论（八股文）

**Redis 与数据结构：**

- Redis 的 Bitmap 大概是一个什么样的物理结构？
- 布隆过滤器（Bloom Filter）大概讲讲它是什么样的数据结构？

**操作系统：**

- 你是怎么理解操作系统里的 CPU 调度的？
- 如果让你来实现短任务或优先级的 CPU 调度，你大概会用什么样的数据结构？
- （针对候选人回答的哈希+数组）如果是这样，找到最小优先级的时间复杂度是多少？如果用 TreeMap 呢？
- 你了解过 Linux 操作系统是怎么存储（或实现）调度的吗？

**算法理论：**

- 排序算法的时间复杂度下界（下限）是什么？
- 你了解过比 O(N log N)更快的排序算法吗？最快是不是能达到 O(N)（比如桶排序）？

**数据库：**

- 数据库索引的物理结构是什么样的？
- B+ 树大概是一个什么样的结构？
- 执行一条 `SELECT` 语句去查找一条数据，它在 B+ 树里执行的时间复杂度是什么样的？

### 四、 手撕代码环节

1. **编程题 1**：螺旋打印二维数组。
2. **编程题 2**：版本号排序。

- 给定一个存储版本号的字符串数组，按版本号从小到大排序。可以直接用内置的排序方法写（不需要手写快排或归并）。
