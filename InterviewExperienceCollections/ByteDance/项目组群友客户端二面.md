#

3.13-字节客户端二面

📌 一、 个人背景与求职意向

1. **自我介绍：** 简单做一个自我介绍。
2. **跨端求职动机：** 你之前的经历主要是后端/服务端开发，为什么会考虑在客户端方面做尝试？
3. **客户端基础了解：** 之前对客户端相关的开发有了解过吗？都了解了哪些东西？
4. **前后端差异理解：** 你认为客户端开发跟服务端开发有哪些比较大的差异点？
5. **实习意向确认：** 目前的实习时间安排是怎样的？未来发展倾向于做服务端还是客户端？

📌 二、 Java基础与并发编程（核心考察：线程池）

1. **核心参数：** 创建 Java 线程池时，一般有哪些核心参数？
2. **执行流程：** 线程池在执行任务时，完整的处理流程是怎样的？
3. **线程回收：** 核心线程会被回收吗？我们可以主动去回收它吗？
4. **拒绝策略：**
   - 比较常见的拒绝策略有哪几种？
   - 在生产环境中，一般会使用哪种拒绝策略？
   - 如果要自定义拒绝策略，应该怎么做？一般用在什么场景下？
   - **场景题：** 如果业务场景不希望丢弃任务，有什么方式或策略能保证任务不被丢弃？（考察动态扩容、消息队列缓存等思路）
5. **线程数设置：** 线程池的核心线程数一般会怎么设置？（考察 CPU 密集型和 IO 密集型的配置区别及原因）。
6. **多线程池场景题：** 如果在一个项目中创建了多个线程池，且每个线程池的核心线程数都等于 CPU 核心数，这会导致总线程数远超 CPU 核心数。这种现象会引发什么问题？如何解释这种设置的合理性？（考察对上下文切换、IO阻塞等待的理解）
7. **线程复用原理：** JDK 原生的线程池中，线程复用的底层原理是怎样的？（考察 Worker 是如何不断从 BlockingQueue 获取任务的）

📌 三、 计算机网络

1. **TCP 与 UDP：** TCP 和 UDP 分别适用于哪些应用场景？
2. **HTTP 请求方法：** PUT 和 POST 请求有什么区别？哪个不具有幂等性？
3. **网络全流程：** 从浏览器输入一个 URL 到页面最终展示，整个过程是怎样的？
4. **DNS 解析：** DNS 域名解析发生在网络七层模型中的哪一层？（应用层）

📌 四、 AI 大模型与工具应用

1. **日常应用场景：** 你在简历中提到使用过 AI 辅助开发工具，日常开发中具体会在哪些场景下使用 AI？
2. **任务分配倾向：** 对于已知并掌握的技能任务，你是倾向于让 AI 直接写代码，还是自己来写？
3. **学习新领域：** 如果面临一个完全没有接触过的新行业或新领域，你会如何利用工具去学习？
4. **大模型优势理解：** 你觉得现在的 OpenAI（大模型）能替我们做哪些事情？它与传统 AI 相比，最大的优势在哪里？
5. **Agent（智能体）概念：** 了解过大模型 Agent 吗？它跟基础的大模型对话（Chat）有什么区别？
6. **大模型 Skills（技能）原理：** 你了解过大模型是如何调用技能（Skills/Tools/Functions）来实现自动化操作的吗？（考察对 Function Calling 的理解）
